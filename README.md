Solara Bay: Neon Shores is an original open-world crime game for desktop Chrome: explore a sun-soaked coastal city on foot and by car, steal and drive seven vehicle models, run from a five-star SBPD wanted system, and play a six-mission story of fixer Maya Sol, boat mechanic Rafi Vale and the Cannery Kings — with traffic, pedestrians, combat, a live minimap HUD, synthesised WebAudio sound and localStorage saves, all from static files with no build step and no network requests.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in desktop Chrome
```
